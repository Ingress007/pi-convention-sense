## 1. 结论

- **Observe：可进入受控试用。** Scope、仓库隔离、候选排序、Context 注入、token 与性能满足本阶段门槛。
- **Guard：继续保持 experimental opt-in。** 真实项目中的补救路径没有死锁，且没有永久阻塞；但当前证据只覆盖一个企业 Java 仓库，跨模块 fallback 仍有局部代表性风险，真实 TUI `/tree`、bypass 与完整 pi-lens 共存尚未在本轮全部复测，因此不建议默认生产启用。

### 保守认可口径

自动分析能确认同 role 和同 module，但不能替代业务语义判断。因此 Top-K 认可率采用更保守口径：只有同 leaf module 候选计为认可。唯一跨模块样本是 `server-ui/WebController`：

- `server-web/WebController` 与目标职责高度相似；
- 其余 3 个 REST Controller 只能提供 Spring Controller 的宽泛结构证据；
- 对该目标的 Observation 仍是真实 peer 事实，但局部代表性弱；
- 该目标计入潜在误拦截风险，不以自动同-role 结果冒充人工业务确认。

独立新进程按顺序读取 7 个文件：Controller、ServiceImpl、Mapper、Request DTO、Response DTO、weak Service interface 和 protobuf 生成文件。

当前开发会话曾在修复前缓存过 protobuf Snapshot；该历史 Context 不计入指标。全新独立进程是 generated-source 行为的判定依据。

## 5. 真实 Pi Guard worktree 实验

### 5.1 Existing target

1. 未 read 即 edit `JobController`：`TARGET_NOT_READ → block`；
2. read 成功并产生 valid Snapshot；
3. Snapshot 注入 Context 后重试：`SNAPSHOT_VALID → allow`。

### 5.2 Prospective write

1. 首次 write 新 Controller 前生成 prospective valid Snapshot；
2. Snapshot 尚未进入模型 Context：`SNAPSHOT_NOT_INJECTED → block`；
3. 下一轮 Context 注入后原样重试：`SNAPSHOT_VALID → allow`。

### 5.3 Weak fail-open

1. read `RetryApiService` 后得到 weak Snapshot；
2. edit 决策：`SNAPSHOT_WEAK_DISCOVERY_COMPLETE → allow`；
3. weak Evidence 没有形成永久阻塞。

### 5.4 Shell 后置审计

Shell 向未覆盖的 `WorkflowController` 追加测试注释：

- Shell 未做不可靠的命令全文解析；
- 执行前后 Git baseline 发现 1 个 changed Java file；
- `evidenceGapCount=1`；
- 下一轮 Context 可注入缺口；
- 已 dirty 文件二次修改的回归用例继续通过。

## 6. 本轮真实项目驱动修复

1. **跨仓库 Evidence 污染**：目标路径解析独立 Git/Maven repository root。
2. **泛化 `*VO` 角色**：request/response package 可覆盖泛化 VO 后缀。
3. **Handler 误判 DTO**：package override 只作用于已有 DTO 后缀，不再把任意 `request` 目录类判为 DTO。
4. **生成源码混入 Evidence**：识别 `Generated by ... DO NOT EDIT` 源码头；目标与候选都排除。
5. **DTO 长期 weak**：增加 DTO 命名、Lombok、Bean Validation 与 Serializable Evidence。
6. **可共存 wrapper 被判 Mixed**：additive signal 不再按互斥模式处理。
7. **重复 Context**：同 Scope 只注入最新或当前 Guard 目标的一个 Snapshot。
8. **formatter 歧义**：候选被 token 预算裁剪时显示 `showing X of Y`，Scope 不再截断。

所有修复均有自动回归测试；当前结果为 **39/39**。

## 7. 未关闭风险

1. `server-ui` 单 Controller 会 fallback 到 sibling `server-web`，其中部分 peer 只具宽泛结构可比性。
2. `RetryTaskMapper` 和 `RetryApiService` 为 weak；当前 fail-open 正确，但说明这些角色的可提炼结构信号有限。
3. 只评估了一个大型 Maven Java 仓库，尚不足以证明跨组织生产泛化能力。
4. bypass 与 Branch 隔离已有自动集成测试，本轮未在真实仓库 TUI 手工重复 `/convention-bypass` 与 `/tree`。
5. 本轮独立 Pi 子进程使用 `--no-extensions` 后显式加载 Convention Sense，尚未完成与全部 pi-lens 扩展同时开启的修改流测试。
6. High Observation 的 100% 是源码结构一致性，不等同于独立业务专家对“是否值得采用”的 100% 认可。
